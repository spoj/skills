# Inspire

This skill provides words that may inspire you. Treat them as thought expanders, not constraints.

Call when you have too much open space to explore, or when you think you have explored all angles.

## Use

From this skill directory:

```bash
python3 inspire.py
```

Optional reproducible draw:

```bash
python3 inspire.py --seed 7
```

Use the words to notice new angles, then keep only what is useful.
